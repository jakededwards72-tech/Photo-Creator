# Forge AI Studio

Mobile-first AI image creator/editor. Supports text-to-image and image-to-image editing.

## Local setup
1. npm install
2. Copy .env.example to .env.local
3. Add your OpenAI API key
4. npm run dev

## Vercel
Import this GitHub repository into Vercel. Add OPENAI_API_KEY in Project Settings > Environment Variables. Optionally set OPENAI_IMAGE_MODEL (defaults to gpt-image-2). Deploy.

Never commit your API key.
